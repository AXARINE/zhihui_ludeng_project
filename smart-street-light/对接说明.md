## 方式二：自己本地跑一套（用本文件夹的文件）

### 1. 建数据库

装好 PostgreSQL 12+ 后，先建库再导入脚本（两步）：

```bash
psql -U postgres -c "CREATE DATABASE smart_street_light;"
psql -U postgres -d smart_street_light -f smart_street_light.sql
```

### 2. 装依赖 + 启动

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

或者直接双击根目录 **`启动智慧路灯.bat`**（自动检测 Python、启动服务、打开浏览器）。

## 关键差异（重要！）

项目数据库是 **PostgreSQL**（不是 MySQL），对接时注意：

- 表 `user` 已改名 **`users`**（`user` 是 PostgreSQL 保留字）
- 自增主键用 `GENERATED BY DEFAULT AS IDENTITY`，插入后可用 `RETURNING id` 拿新主键
- 无 `ON UPDATE CURRENT_TIMESTAMP`，更新时间由后端显式写 `updated_at`

## 接口一览（详见 `backend/README.md`）

| 模块 | 接口 |
|------|------|
| 账号管理 | `GET/POST /api/users`、`DELETE /api/users/{id}`、`GET /api/roles` |
| 设备管理 | `GET/POST /api/devices`、`DELETE /api/devices/{id}` |
| 数据采集 | `POST /api/data/luminance`、`/heartbeat`、`/alarm`（自动注册未知设备） |
| 阈值/控制 | `POST /api/thresholds`、`/api/control/auto`、`/api/control/manual` |
| 告警 | `POST /api/alarms/{id}/resolve` |
| 智能问答 | `POST /api/assistant/ask` |
| 查询 | `GET /api/alarms`、`/api/luminance`、`/api/commands`、`/api/health` |
